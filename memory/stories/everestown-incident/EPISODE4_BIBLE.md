# Everestown — Эпизод 4 (рабочая библия)

## Стартовая точка (жёсткий канон)
- Прямое продолжение после финала эпизода 3 (Север-12).
- Зафиксированный хук: в зоне без узлов зафиксировано **двойное мигание**.
- Последняя реплика Касымова: «вторая линия была не одна».

## Ключевой конфликт эпизода
- Нужно установить природу «второй линии»: это человек/группа, технический контур или иной режим отклика глубины.
- Безопасностная цель Ады: локализовать угрозу без паники и без разрыва критических контуров.
- Познавательная цель: связать оперативные факты Север-12 с историческим редактированием «Песни глубины».

## Обязательные опоры мира
- Сеттинг: техно-среда Эверестауна (уровни, узлы, дампы, контуры), мистический слой только через наблюдаемые аномалии.
- Никакой «магии из ниоткуда»: каждое странное явление должно иметь инженерный след (лог, ритм, трасса, носитель).
- Переходы между локациями — только через показанный маршрут/время/цену.

## Состояние персонажей на входе
- **Ада Воронцова** — в поле, ведёт решение и риск.
- **Марат Касымов** — найден на Север-12, в нестабильном состоянии, источник критичного знания о «втором ответе».
- **Ирина Орлова** — канал историко-архивной верификации.
- **Ремезов / Лев** — опорные контуры стабилизации и безопасности.
- **Элина Ветринская** — подтверждённый факт управляемой переработки гражданской версии «Песни».

## Тон и жанровый режим
- Sci-fi + нарастающий тревожный мистический слой.
- Саспенс через детали среды: звук, конденсат, задержки связи, ложная нормальность инфраструктуры.
- Без резких жанровых скачков в хоррор.

## Нарративные запреты
- Не обнулять факты предыдущих эпизодов.
- Не вводить крупные сущности без фиксации в CONTINUITY/CHARACTERS/WORLD_RULES.
- Не делать «случайные откровения» без следов в данных/сцене.

## Пролог эпизода 4 должен сделать
1. Зафиксировать последствия события на Север-12 (двойное мигание и «вторая линия»).
2. Поставить Аду перед первым решением эпизода.
3. Дать ощущение, что угроза уже внутри инфраструктуры, а не снаружи.
4. Завершиться чётким триггером к сцене 1.
